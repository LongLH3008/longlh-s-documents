# Frontend

> Mục lục các kỹ thuật frontend.

## Tài liệu

### Trình duyệt và DOM

- [DOM](./dom.md): cây DOM, truy cập và thao tác phần tử
- [DOM Dimensions](./dom-dimensions.md): kích thước, vị trí phần tử (offset, client, scroll)
- [Shadow DOM](./shadow-dom.md): đóng gói DOM và style cho Web Component
- [Event Delegation](./event-delegation.md): gắn một listener ở phần tử cha để xử lý nhiều phần tử con

### Web API

- [AbortController](./abort-controller.md): hủy fetch và các tác vụ bất đồng bộ
- [IntersectionObserver](./intersection-observer.md): theo dõi phần tử đi vào/ra khỏi vùng nhìn
- [MutationObserver](./mutation-observer.md): theo dõi thay đổi của DOM
- [REST API và Fetch](./rest-api.md): JSON Server, Postman, gọi API bằng fetch
